# Python Expense Tracker

A console-based Expense Tracker application built with Python.

## Features

- Add expenses
- View expenses
- Summarize expenses by category
- Persistent storage using `expenses.txt`
- Amount validation
- Date validation
- Category validation
- Error handling
- Object-Oriented Programming
- Modular Python structure

## Expense Information

Each expense contains:

- Amount
- Category
- Date

Date format:

YYYY-MM-DD
